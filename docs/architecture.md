# Architecture

This document describes the high-level architecture and design decisions for the `terraform-gke-production` project.

## Objectives

The primary objective of this project is to provision and manage a production-ready Google Kubernetes Engine (GKE) platform on Google Cloud using Terraform.

The infrastructure will be designed with the following principles:

* Modularity
* Security by default
* Scalability
* Reusability
* Maintainability
* Automation
